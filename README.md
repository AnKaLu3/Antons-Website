## Editing

Edit the HTML files for text, styles.css for styling, and replace the named image files for photographs. The site uses plain HTML, CSS, and JavaScript. Preview locally with `python3 -m http.server 8765 --bind 127.0.0.1`, then open http://127.0.0.1:8765/. Commit changes to main to publish updates.
